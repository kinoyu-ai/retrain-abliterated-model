# LoRA Adapter for `huihui-ai/Huihui-Qwen3.8-27B-abliterated` (Benign Dolly QLoRA Distillation)

**English** | [Qwen3.8-27B README](../README.md) | [日本語 README](../README.ja.md) | [Root README](../../README.md)

This directory contains the PEFT LoRA adapter (`adapter_model.safetensors`, ~66.0 MB) and its `llama.cpp` GGUF v3 conversion (`qwen38-dolly-lora-f32.gguf`, ~66.0 MB) trained on [`huihui-ai/Huihui-Qwen3.8-27B-abliterated`](https://huggingface.co/huihui-ai/Huihui-Qwen3.8-27B-abliterated) using 500 benign Japanese QA responses generated by [`Qwen/Qwen3.8-27B`](https://huggingface.co/Qwen/Qwen3.8-27B).

## Model Details

- **Developed by:** kinoyu-ai
- **Base model:** `huihui-ai/Huihui-Qwen3.8-27B-abliterated` (`739e3c5b89849f6c238ce1e5b70008612ae42cdd`)
- **Teacher model (distillation source):** `Qwen/Qwen3.8-27B` (`37561816e66b5b9153b1b64c10968c18c1e6f4a0`)
- **Training data:** 500 complete, non-empty teacher answers from 5 benign categories of [`llm-jp/databricks-dolly-15k-ja`](https://huggingface.co/datasets/llm-jp/databricks-dolly-15k-ja) (CC BY-SA 3.0). Zero safety/refusal prompts were included in training.
- **LoRA configuration:** `r=8`, `lora_alpha=16`, `lora_dropout=0.0`, `bias="none"`, `target_modules=["o_proj", "out_proj", "down_proj"]` (`17,301,504 / 26,913,299,968 = 0.0643%` trainable parameters)
- **Optimization:** 4-bit NF4 QLoRA (`bfloat16` compute), `AdamW` (`lr=1e-4`), gradient accumulation `8`, `1` epoch (`63` steps), gradient clipping `1.0`, `gradient_checkpointing(use_reentrant=False)`, loss computed on answer tokens + EOS only
- **Framework versions:** PyTorch `2.13.0+rocm10.0`, Transformers `5.23.0`, PEFT `0.21.3`, bitsandbytes `0.50.2`
- **License:** Apache License 2.0

## Key Results

See the [Qwen3.8-27B README](../README.md) for the full 10,206-prompt evaluation (`student` vs `trained`). Highlights:

- **Knowledge & Japanese QA gains:** `MMLU` (`81.12%` -> `81.91%`, +0.78 pt), `ARC-Challenge` (`96.42%` -> `96.67%`, +0.26 pt), `JCommonsenseQA` (`95.44%` -> `95.62%`, +0.18 pt), and held-out Japanese Dolly (`reference char 3-gram F1` `0.1771` -> `0.1856`, truncation `44/100` -> `39/100`).
- **Preserved abliteration profile:** Across `XSTest` (450), `StrongREJECT` (313), `AdvBench` (520), and `XSTest Privacy` (50), non-refusal behavior is preserved with 0 substantive refusal revivals.
- **Thinking-mode (`reasoning_effort="xhigh"`) loop behavior:** On 30 loop-inducing prompts (`max_tokens=4096`), official sampling (`temperature=1.0, top_p=0.95, top_k=20`) yields 0 exact loops, shortens reasoning characters on 22/30 prompts (mean -19.8%, `p=0.0161`), and raises clean `<2,048`-token completions (`6 -> 11 / 30`). Avoid greedy decoding (`temperature=0`) in `xhigh` mode, where pathological loops remain (`4 -> 6 / 30`).

## Usage

### Transformers + PEFT

```python
import torch
from peft import PeftModel
from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig

base_id = "huihui-ai/Huihui-Qwen3.8-27B-abliterated"
tokenizer = AutoTokenizer.from_pretrained(base_id)
base_model = AutoModelForCausalLM.from_pretrained(
    base_id,
    quantization_config=BitsAndBytesConfig(
        load_in_4bit=True,
        bnb_4bit_quant_type="nf4",
        bnb_4bit_use_double_quant=True,
        bnb_4bit_compute_dtype=torch.bfloat16,
    ),
    device_map="auto",
    dtype=torch.bfloat16,
)
model = PeftModel.from_pretrained(base_model, "./qwen38-27b/adapter")
model.eval()
```

### `llama.cpp` / `llama-server` (GGUF LoRA)

```bash
llama-server \
  --model Huihui-Qwen3.8-27B-abliterated-UD-Q5_K_XL.gguf \
  --lora ./qwen38-27b/adapter/qwen38-dolly-lora-f32.gguf \
  --jinja --flash-attn on
```

## Limitations & Risks

This adapter is intended for research on abliteration recovery and distillation dynamics. Because it preserves the non-refusal behavior of the abliterated base model, it does not enforce safety refusals on harmful requests and should not be deployed directly in safety-critical or unrestricted user-facing environments without appropriate external safeguards.
