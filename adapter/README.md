# LoRA Adapter for `orcarouter/LFM3-1.7B-abliterated` (Benign Dolly Distillation)

**English** | [Root README](../README.md) | [日本語 README](../README.ja.md)

This directory contains the PEFT LoRA adapter (`adapter_model.safetensors`, ~10.6 MB) trained on [`orcarouter/LFM3-1.7B-abliterated`](https://huggingface.co/orcarouter/LFM3-1.7B-abliterated) using 500 benign Japanese QA responses generated by the original teacher model [`LiquidAI/LFM3-1.7B`](https://huggingface.co/LiquidAI/LFM3-1.7B).

## Model Details

- **Developed by:** kinoyu-ai
- **Base model:** `orcarouter/LFM3-1.7B-abliterated` (`9fded8f990462fa0a0b6439805d1065933ac199e`)
- **Teacher model (distillation source):** `LiquidAI/LFM3-1.7B` (`1da06bec6a819da10b54c67e5c90972b46d81871`)
- **Training data:** 500 complete, non-empty teacher answers from 5 benign categories of [`llm-jp/databricks-dolly-15k-ja`](https://huggingface.co/datasets/llm-jp/databricks-dolly-15k-ja) (CC BY-SA 3.0). Zero safety/refusal prompts were included in training.
- **LoRA configuration:** `r=8`, `lora_alpha=16`, `lora_dropout=0.0`, `bias="none"`, `target_modules=["o_proj", "out_proj", "w2"]` (`2,654,208 / 1,731,455,744 = 0.1533%` trainable parameters)
- **Optimization:** `AdamW` (`lr=1e-4`), gradient accumulation `8`, `1` epoch (`63` steps), gradient clipping `1.0`, `bfloat16`, loss computed on answer tokens + EOS only
- **Framework versions:** PyTorch `2.13.0+rocm10.0`, Transformers `5.23.0`, PEFT `0.21.3`
- **License:** Subject to the **LFM 1.0 License** of the base/teacher models.

## Key Results

See the [root README](../README.md) for the full 15-benchmark (14,545-prompt) 3-way comparison (`teacher` vs `student` vs `trained`). Highlights:

- **Coding & reasoning recovery:** Recovers and exceeds the original teacher model on `ARC-Challenge` (`59.90%` -> `64.59%`), `MMLU` (`46.31%` -> `49.71%`), `GSM8K` (`65.13%` -> `68.54%`), `BoolQ` (`46.30%` -> `51.28%`), `HumanEval` (`40.85%` -> `58.54%`), and `MBPP` (`41.63%` -> `52.14%`).
- **Preserved abliteration profile:** Across 4,196 refusal/over-refusal prompts (`XSTest`, `AdvBench`, `StrongREJECT`, `OR-Bench`, `Do-Not-Answer`), refusal behavior does not return (`AdvBench` `0.38%`, `StrongREJECT` `0.00%`, `OR-Bench Hard-1k` `0.08%`).

## Usage

```python
import torch
from peft import PeftModel
from transformers import AutoModelForCausalLM, AutoTokenizer

base_id = "orcarouter/LFM3-1.7B-abliterated"
tokenizer = AutoTokenizer.from_pretrained(base_id, trust_remote_code=True)
base_model = AutoModelForCausalLM.from_pretrained(
    base_id,
    trust_remote_code=True,
    dtype=torch.bfloat16,
    device_map="auto",
)
model = PeftModel.from_pretrained(base_model, "./adapter")
model.eval()
```

## Limitations & Risks

This adapter is intended for research on abliteration recovery and distillation dynamics. Because it preserves the non-refusal behavior of the abliterated base model, it does not enforce safety refusals on harmful requests and should not be deployed directly in safety-critical or unrestricted user-facing environments without appropriate external safeguards.
